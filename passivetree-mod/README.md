# Passive Tree (Forge 1.20.1) - Phase 1

A Path of Exile 2 style passive skill tree.

## Build with GitHub (no install needed)
1. Create a new repository on github.com
2. Upload ALL files from this folder (including the hidden `.github` folder)
3. Open the **Actions** tab -> wait for "Build mod" to finish (green check)
4. Open the finished run -> **Artifacts** -> download `passivetree-jar` -> unzip
5. Put `passivetree-0.1.0.jar` into the `mods` folder of your Forge 1.20.1 profile

## In game
- Press **K** to open the tree, choose a class.
- Points = highest XP level you reached + bonus points.
- Testing: `/passivetree points add 30` (needs cheats / OP)
- `/passivetree respec` resets your tree; `/passivetree resetclass` (OP) lets you pick another class.
